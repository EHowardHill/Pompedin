Bundled binaries (sidecar, invoked as a separate process):
  • Windows x64:  ffmpeg-x86_64-pc-windows-msvc.exe
      gyan.dev "essentials" build
      version 2026-03-09-git-9b7439c31b (verified via `ffmpeg -version`)
      configuration includes --enable-gpl --enable-version3
      --enable-libx264 → licensed under GPLv3
  • macOS ARM:     ffmpeg-aarch64-apple-darwin
      evermeet.cx build (see docs/FFMPEG-LICENSING.md for the pin and
      verification steps — treat as a GPL build)
  • Linux:         no binary is bundled; ffmpeg is expected from the
      system package manager (e.g. `sudo apt install ffmpeg`).
