1. Getting Started

Pompedin is a vector-based 2D animation tool. Your drawings live as Keyframes on a timeline — drawing on a blank frame automatically creates a keyframe.

Use the Project tab to set canvas size, frame rate (FPS), animation length, film grain, and audio. Use the Workspace tab to change the theme, canvas background, tablet input mode, and to customize your keyboard shortcuts (see section 8).

2. Drawing Tools

Default keys follow the Moho Pro 13.5 layout and are all remappable.

  • Brush (F): draws vector strokes. The Brush tab adjusts size, smoothing, spacing, rotation/jitter dynamics, pen pressure, and bitmap textures applied along the vector path.
  • Eraser (E): removes whole paths or segments under the cursor.
  • Fill / Paint Bucket (P): click inside a closed shape to fill it. Toggle Fill and Stroke in the Home tab to control what gets applied.
  • Hide Edge (H): click or drag over a line segment to hide it while keeping the underlying vector shape intact — great for cel-shading joins.
  • Eyedropper (L): sample a color. You can also hold Left Alt to pick a stroke color or Right Alt for a fill color.

3. Selection & Editing

The Select / Edit tool (T) works in two modes:

  • Object Mode: click a shape to select it; a bounding box lets you move, scale, and rotate it.
  • Vertex Mode: double-click a selected shape to reveal its anchor points, then drag points or their Bézier handles. Press Esc or click empty space to exit.

The Lasso (G) selects points inside a freeform region. The Tools tab adds Path Tools (Simplify, Smooth, Close, Reverse), Boolean Ops (Union, Subtract, Intersect, Exclude — needs two closed paths), Align & Distribute, Flip, and Select All. Symmetry mirrors new strokes across adjustable axes, and Canvas Guides add a grid, safe zones, and center/rule-of-thirds overlays.

4. Layers & Timeline

Pompedin supports unlimited layers; the timeline controls when artwork appears.

  • New Frame (F5): inserts an empty keyframe at the playhead.
  • Duplicate Frame (F6): copies the current frame's artwork into a new keyframe.
  • Delete Frame (Shift+F5): removes the keyframe at the playhead.
  • Tweening: right-click a keyframe and choose Toggle Tween to interpolate vector shapes (or image transforms) between keys. The ↳ Transform track keyframes a layer's position, rotation, and scale.
  • Loops: right-click a keyframe → Loop Settings to repeat a span of frames (relative or absolute).
  • Onion Skin: toggle it in the Brush tab or with the onion bar under the timeline ruler; add or drag rules, and scroll a marker to fade it.
  • Layer Settings (⚙ or double-click a layer): rename, set blend mode, lock, mark as Reference (excluded from export), assign a color tag, and enable Sketch Wobble for a hand-drawn boil.

Drag layers to reorder them. Right-click any timeline cell to copy, paste, insert, or remove frames, and drag keyframes (or marquee-select several) to move them around.

5. Camera

The Camera tool (4) and the Tools tab let you keyframe a virtual camera — position, zoom, and rotation — on its own timeline row. Values interpolate between keys for smooth pans, pushes, and rolls, and the camera is baked into every export. Set or delete camera keys from the Tools tab or by right-clicking the Camera row. Note that Rotate Workspace (8) only spins your view and does not affect the camera or the output.

6. Audio Syncing

Import an audio file for lip-syncing and timing from the Project tab → Load Audio. A waveform appears beneath the timeline ruler and scrubs as you play. Volume is set there and is mixed into MP4 exports automatically. For the widest cross-platform preview support, use WAV, MP3, or AAC/M4A files.

7. Exporting

All options live in the Export tab.

  • Frame (PNG): exports the current frame.
  • Sequence: exports every frame as an individual numbered PNG.
  • Video (MP4): renders the animation to video, mixing in your audio track. FFmpeg is bundled on Windows & macOS; on Linux, install it with your package manager (e.g. sudo apt install ffmpeg or sudo dnf install ffmpeg).
  • Animated GIF: a looping GIF with adjustable color count and dithering.
  • Spritesheet: tiles all frames into one PNG (set columns and padding) — ideal for game engines.

The Range & Scale controls set which frames export and at what output size.

8. Customizing Shortcuts

Pompedin ships with the Moho Pro 13.5 keyboard layout, and every tool/navigation shortcut is remappable. Open the Workspace tab → Shortcuts, click any binding, then press the key or combination you want (Esc cancels). Conflicting bindings are cleared automatically, your map is saved locally, and Reset to Moho Defaults restores everything.

The core editing combos (Undo/Redo, Copy/Cut/Paste, Save, Select All), the bracket keys, Space, Esc, and Delete are fixed and can't be reassigned.

9. Keyboard & Mouse Shortcuts

Tool and navigation keys below are the defaults — remap them in the Workspace tab. On macOS, Cmd works in place of Ctrl.

Tools

  • T — Select / Edit
  • F — Brush
  • G — Lasso
  • E — Eraser
  • P — Fill (Paint Bucket)
  • H — Hide Edge
  • L — Eyedropper
  • M — Translate Layer
  • R — Rotate Layer
  • S — Scale Layer
  • 4 — Camera
  • 8 — Rotate Workspace
  • Z — Zoom Workspace

Playback & Frames

  • Space — Play / Stop
  • ← / → — Previous / Next Frame
  • F5 — New Frame
  • F6 — Duplicate Frame
  • Shift + F5 — Delete Frame
  • ↑ / ↓ — Select Layer Above / Below

View & Canvas

  • Home — Reset View
  • Shift + Home — View All (Fit to Screen)
  • Ctrl + G — Toggle Grid
  • Ctrl + L — Toggle Onion Skins
  • Shift + H / Shift + V — Toggle Horizontal / Vertical Symmetry

Editing (fixed)

  • Ctrl + Z — Undo
  • Ctrl + Shift + Z / Ctrl + Y — Redo
  • Ctrl + S — Save · Ctrl + Shift + S — Save As
  • Ctrl + C / X / V — Copy / Cut / Paste items or keyframes
  • Ctrl + A — Select All
  • [ / ] — Decrease / Increase stroke width (hold Shift for ×5)
  • Esc — Deselect / Exit vertex mode
  • Delete / Backspace — Delete selected items or keyframes

Mouse

  • Right-Click drag (or pen side button) — Pan canvas
  • Scroll Wheel — Zoom canvas
  • Middle-Click or Ctrl + Left-Click drag — Zoom, anchored at the cursor
  • Double-click a shape — Enter vertex edit mode
